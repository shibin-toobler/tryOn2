# TryOn2

Personalized fashion shopping prototype built with Next.js, TypeScript and Tailwind CSS.

## Features
- Personalized product recommendations
- Style, fit, color and body-fit controls
- Recommendation reasons on every product
- Virtual Try-On side panel
- User photo upload
- Mock generated try-on result
- Responsive layout

## Run locally
```bash
npm install
npm run dev
```

The current try-on result is a UI prototype. A real AI try-on API can be connected later.
